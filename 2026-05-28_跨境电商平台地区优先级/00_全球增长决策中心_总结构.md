# 全球增长决策中心：总结构

## 产品定位

全球增长决策中心是一个面向市场团队、增长团队、出海品牌团队、平台服务商和销售支持团队的内部工作台。

它把“市场判断、内容选题、营销排期、数据可信度”放在同一个系统里，但不同模块承担不同职责：

```text
判断层：全球市场与平台优先级看板
沉淀层：全球内容选题决策工具
执行层：营销日历生成器
校验层：数据来源中心 / 更新状态监控
```

## 总层级

```text
Global Growth Workspace
├── 首页 / 工作台
│   └── 点击左上角 Decision Center 进入
├── Tools
│   ├── 全球市场与平台优先级看板
│   ├── 全球内容选题决策工具
│   └── 营销日历生成器
└── System
    ├── 数据来源中心
    └── 更新状态监控
```

## 首页定位

首页不是独立工具，因此不放在左侧导航栏里。

用户通过点击左上角 `Decision Center.` 回到首页。

首页负责回答：

```text
我现在该先进哪个工具？
哪些事项需要处理？
最近生成了什么？
哪些数据可以用，哪些需要复核？
```

首页不负责展示具体市场看板数据，避免和“全球市场与平台优先级看板”的总览重复。

### 首页模块

```text
Hero 简介
├── 说明系统从市场信号到日历执行的工作流

今日工作流
├── 01 判断国家/地区与平台优先级
├── 02 筛选内容主题和目标受众
└── 03 生成营销月历和发布计划

待处理队列
├── 待复核节点
├── 待排期选题
├── 待更新数据
└── 日历模板

最近生成
├── 全球营销节点预览
├── Prime Day 内容选题包
└── 单一国家示范月历

数据健康
├── 市场数据状态
├── 平台活动状态
├── 赛事 / 峰会复核状态
└── 高风险市场确认状态
```

## 工具一：全球市场与平台优先级看板

### 职责

判断哪些国家/地区、平台、客单价区间、利润空间和风险项值得优先关注。

### 页面

```text
总览
市场平台
客单利润
卖家类型
市场简评
数据口径
```

### 输出

```text
高价值国家/地区
重点平台
市场分层
客单价判断
利润潜力
成本风险
适合受众类型
是否需要人工复核
```

### 下游

```text
全球内容选题决策工具
营销日历生成器
```

## 工具二：全球内容选题决策工具

### 职责

把市场、平台、受众、时间节点、趋势和内容形式组合成可筛选、可复用、可进入营销日历的选题库。

### 页面

```text
总览
市场平台
卖家类型
时间节点
选品趋势
选题库
```

### 输出

```text
选题标题
目标国家/地区
国家/地区缩写
目标平台
目标受众
关联时间节点
关联选品趋势
内容角度
建议内容形式
优先级
复核状态
是否发送到营销日历
```

### 下游

```text
营销日历生成器
```

## 工具三：营销日历生成器

### 职责

把市场判断和内容选题排成可执行的月历、周计划和发布清单。

### 页面


后续完整阶段可扩展：

```text
生成器
模板库
月历视图
周计划
导出记录
```

### 输出

```text

Excel / CSV
Notion 表格
社媒排期表
朋友圈发布计划
海报制作清单
短视频脚本方向
```


## 数据流

```text
全球市场与平台优先级看板
    ↓
提供国家/地区、平台、利润、风险、受众判断
    ↓
全球内容选题决策工具
    ↓
沉淀选题、节点、趋势、内容形式、复核状态
    ↓
营销日历生成器
    ↓
生成月历、周计划、社媒发布表、海报主题清单
    ↓
数据来源中心 / 更新状态监控
    ↺
反向校验数据可信度和复核状态
```

## 国家/地区展示规则

在营销日历中：

```text
国家/地区用缩写徽标
事件类型用颜色
抽屉里显示完整国家/地区名称和事件说明
```

示例：

```text

DE = 德国

SEA = 东南亚
LATAM = 拉美
GCC = 中东/GCC
AMZ = Amazon 平台活动
PLAT = 平台通用节点
XBD = 跨境泛话题
```

## v4 预览版说明

v4 HTML 是交互和信息架构预览，不是完整内容库。

当前重点验证：

```text
首页是否更像工作台
左侧 Tools 是否拆成三个一级工具
营销日历是否从内容工具中独立出来
国家/地区缩写是否比旗帜和长标签更简约
日历事件点击后是否显示事件级详情
俄罗斯是否被明确为示范模板之一
```

后续完整版本需要补充：

```text
完整市场平台库
完整受众类型库
完整客单利润表
完整社媒平台和电商平台选项
完整时间节点库
完整选题库
真实数据来源和更新逻辑
```
