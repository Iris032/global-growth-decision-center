# 全球内容选题决策工具：页面结构

## 工具定位

这是一个面向市场团队、增长团队、品牌出海团队、平台服务商和销售支持团队的内容选题决策工具。

它不负责选择市场，也不负责最终排期。它的核心任务是把“市场、平台、受众、时间节点、趋势和内容形式”组合成可筛选、可复用、可进入营销日历的选题库。

## 与其他工具的关系

```text
输入来源：全球市场与平台优先级看板
使用内容：高价值国家/地区、重点平台、受众类型、市场风险、平台格局、客单价和利润判断

本工具产出：
内容主题
内容角度
受众标签
内容形式
节点关联
趋势关联
优先级
是否需要人工复核

输出到：营销日历生成器
用于生成：月历、周计划、每日社媒选题、朋友圈发布表、海报主题清单
```

## 核心逻辑

```text
高价值国家/地区
+
重要平台
+
目标受众
+
时间节点
+
平台活动
+
商品 / 服装 / 季节性趋势
+
内容渠道
=
可执行内容选题
+
可进入营销日历的排期素材
```

## 工具边界

```text
本工具负责：
├── 判断做什么内容
├── 判断面向谁
├── 判断关联哪个国家/地区、平台、节点或趋势
├── 判断内容形式
├── 标记优先级和复核状态
└── 输出到营销日历生成器

本工具不负责：
├── 生成最终月历
├── 生成周计划
├── 导出发布排期
├── 管理日历模板
└── 维护数据源健康状态
```

## 页面一：总览

### 页面目的

让市场团队快速知道近期最值得做什么内容，以及这些内容来自哪些判断依据。

### 内容模块

```text
标题区
├── 标题：全球内容选题决策工具
├── 副标题：基于国家/地区、平台、受众、时间节点和趋势规划内容选题
├── 当前月份
├── 最近更新时间
└── 数据提示：趋势和节点需要人工复核后再进入正式营销日历

本月重点
├── 高价值国家/地区
├── 重点平台
├── 重点受众类型
├── 近期营销节点
├── 近期平台活动
├── 近期商品选品趋势
└── 近期服装选品趋势

推荐选题方向
├── 国家/地区型选题
├── 平台型选题
├── 节日 / 大促型选题
├── 商品选品趋势型选题
├── 服装趋势型选题
└── 受众痛点型选题

输出入口
└── 发送到营销日历生成器
```

## 页面二：市场平台

### 页面目的

把市场看板里的国家/地区和平台结论转化为内容价值判断。

### 字段结构

```text
国家/地区
国家/地区缩写：US / EU / DE / SEA / LATAM / GCC / GLOBAL
市场优先级
核心平台
主要受众类型
内容价值
适合内容角度
适合内容形式
建议更新频率
是否允许进入营销日历
```

### 内容价值判断示例

```text
美国：适合 Amazon、Prime Day、黑五网一、多平台客服、退货高峰等选题。
东南亚：适合 Shopee、TikTok Shop、双数大促、低价走量、内容电商等选题。
日本：适合 Amazon Japan、Rakuten、本地化、品质型商品、评价管理等选题。
巴西 / 墨西哥：适合 Mercado Libre、本地仓、清关、物流、拉美平台增长等选题。
```
