# 全球市场与平台优先级看板：页面结构

## 工具定位

这是一个“全球市场 / 平台研究底座”看板，用来判断哪些国家/地区、平台、客单价区间、利润空间和风险项值得优先关注。

它不直接生成内容选题，也不直接生成营销日历，而是给后续两个工具提供判断依据：

```text
全球市场与平台优先级看板
输出：高价值国家/地区、重点平台、市场分层、客单价、利润潜力、成本风险、适配受众

输入到：
1. 全球内容选题决策工具
2. 营销日历生成器
```

## 全局中心中的位置

```text
首页 / Global Growth Workspace
├── 全球市场与平台优先级看板
├── 全球内容选题决策工具
├── 营销日历生成器
├── 数据来源中心
└── 更新状态监控
```

首页不重复展示本工具里的市场指标，只负责：

```text
工作流入口
待处理队列
最近生成
数据健康状态
```

## 主要用途

1. 判断哪些国家/地区值得优先研究。
2. 判断不同国家/地区的核心平台、第二选择和第三选择。
3. 判断不同市场的客单价、利润潜力、广告成本、合规成本和履约风险。
4. 判断不同受众类型适合关注哪些市场和平台。
5. 为内容选题和营销日历提供高价值市场、重点平台和风险提示。

## 页面一：总览

### 页面目的

快速给出市场研究结论，让用户先知道哪些国家/地区和平台最值得关注。

### 内容模块

```text
标题区
├── 标题：全球市场与平台优先级看板
├── 副标题：用于判断不同国家/地区的平台优先级、市场价值、客单价、利润空间和风险
├── 整理日期
└── 口径提示：占比主要用于优先级判断，不是财报级精确数据

关键指标
├── 第一梯队市场数量
├── 高利润潜力市场数量
├── 需人工复核市场数量
└── 高风险市场数量

├── 第一梯队：美国、东南亚、印度、日本、巴西

├── 第三梯队：加拿大、澳大利亚、土耳其、波兰、中东/GCC
└── 特殊市场：俄罗斯

重点平台概览
├── Amazon
├── Shopee
├── TikTok Shop
├── Mercado Libre
├── Flipkart
├── Rakuten
├── Coupang
├── Allegro
├── Trendyol
└── Noon
```

### 页面目的

查看每个国家/地区的核心平台、第二选择、第三选择，以及进入状态。

### 筛选条件

```text
国家/地区
市场分层
平台名称
区域类型：北美、欧洲、拉美、亚洲、中东/GCC、全球
利润潜力
风险等级
```

### 主表字段

```text
优先级
国家/地区
市场分层
首选平台
第二选择
第三选择
占比口径
状态：高价值 / 增长 / 区域强势 / 需复核 / 高风险
判断备注
```

### 详情抽屉字段

```text

平台格局说明
适合受众类型

后续需要更新的数据源
是否进入内容选题工具
是否允许进入营销日历
```

## 页面三：客单利润

### 页面目的

区分“市场重要”和“利润空间”，避免只按市场规模判断优先级。

### 内容模块

```text
AOV 概览
├── 各市场估算客单价 USD
├── 人民币粗略换算
└── 客单价排行

利润潜力判断
├── 高
├── 中高
├── 中
├── 中低
└── 中但风险高

成本与风险分类
├── 广告成本
├── 退货成本
├── VAT / EPR / 包装法
├── 清关和税费
├── 支付和资金回流
├── 物流时效
└── 本地化要求
```

### 表格字段

```text
国家/地区
估算客单价 USD
约人民币
利润潜力
主要成本/风险
更适合的打法
是否需要人工复核
```

## 页面四：卖家类型

### 页面目的

从“谁适合进入这个市场”反推平台优先级和内容切入方向。

### 受众类型

```text
泛品 / 白牌 / 低价货卖家
品牌货 / 精品 / 高客单卖家
Amazon 体系卖家
Shopee / TikTok Shop 内容电商卖家
多平台铺货卖家
本地仓 / 海外仓能力卖家
平台服务商 / 代运营 / 物流支付服务商
出海品牌团队
```

### 每类展示字段

```text
推荐平台组合
优先国家/地区
适合品类
关键能力要求
主要风险
不建议优先进入的市场或平台
可输出给内容工具的受众标签
```

## 页面五：市场简评

### 页面目的

用户可以选择任意国家/地区查看简评，不限于重点市场。

### 选择方式

```text
搜索国家/地区
按市场分层切换
按区域类型切换
按平台筛选
按受众类型筛选
按风险等级筛选
```

### 市场卡片字段

```text
国家/地区名称
市场分层
核心平台
平台格局一句话
适合受众类型
适合品类方向
主要风险
更新关注点
可跳转：内容选题 / 营销日历
```

## 页面六：数据口径

### 页面目的

解释数据口径，避免把近似占比误认为精确市场份额。

### 内容模块

```text
占比口径说明
MAU 说明
为什么不同平台占比不能简单相加
AOV 估算说明
品类差异说明
主要参考来源方向
哪些数据需要人工复核
哪些数据可以进入正式选题库
```
