# 跨境电商平台地区优先级看板使用说明

## 文件说明

- `跨境电商平台地区优先级看板.html`：看板页面，直接打开即可查看。
- `data/market-data.js`：看板数据文件，后续自动抓取脚本只需要更新这个文件。
- `跨境电商平台地区优先级.md`：原始整理文档，保留作为文字版依据。

## 当前功能

- 按地区/国家展示平台优先级。
- 支持搜索地区、平台、风险和打法。
- 支持按市场分层、利润潜力筛选。
- 支持按优先级或客单价排序。
- 展示客单价排行、利润潜力、主要风险和适合打法。
- 保留口径说明、参考来源方向、卖家类型平台组合和实操优先级。

## 后续自动更新接入方式

当前看板已经把展示层和数据层拆开：

1. 抓取脚本定期获取公开数据。
2. 脚本清洗成统一字段。
3. 脚本覆盖生成 `data/market-data.js`。
4. 打开或刷新 `跨境电商平台地区优先级看板.html`，页面自动读取最新数据。

后续如果部署到 GitHub Pages、Vercel 或服务器，可以把定时抓取任务设置为每天、每周或每月运行。

## 建议的下一步

先确认这个看板的信息结构是否符合你的判断习惯。确认后，再做第二步：为 Similarweb、平台财报、AOV benchmark 等来源建立自动抓取清单和更新脚本。
